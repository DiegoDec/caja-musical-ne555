4. Splines cúbicos

Se calcula un spline cúbico natural. Con n puntos se obtienen n − 1 tramos. Cada tramo se aplica entre dos tiempos consecutivos.

5. Método de bisección

Ingresa una frecuencia objetivo y selecciona un intervalo de tiempo. Se busca una raíz de g(t) = f(t) − frecuencia objetivo. El intervalo debe encerrar una raíz: g(a) y g(b) deben tener signos opuestos o uno de los extremos debe ser raíz.
